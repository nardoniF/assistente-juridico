Como funciona

Um processo. Uma peça por ação.

Anexe o PDF: o xThemis cria a pasta e grava processo.pdf (só um). Cada ação (recurso, contestação…) vira um Word + um PDF com nome fixo. Enquanto você refina (“faltou X”), ele sobrepoe a mesma peça — sem v1/v2. Quando o tribunal atualizar os autos, use Atualizar processo e o PDF principal é substituído.
